ANALISIS FITUR, MAPPING PBI, SPRINT, DAN OWNERSHIP FILE

Project: MariLancy

Dokumen ini disusun berdasarkan hasil pembacaan struktur project pada layer:
- config
- controllers
- middleware
- models
- routes
- templates
- main.go

Tujuan dokumen:
- Mengidentifikasi fitur yang benar-benar ada di project
- Memetakan fitur ke PBI KF-xx
- Mengelompokkan fitur ke Sprint 1 dan Sprint 2
- Menentukan PIC dan ownership file per anggota
- Merencanakan penandaan komentar Author, PBI, dan Sprint di dalam kode

Catatan:
- Mapping dilakukan berdasarkan fitur yang paling relevan
- Beberapa nomor PBI dipakai ulang dengan nama berbeda, sehingga interpretasi dilakukan dari konteks implementasi
- Sebagian fitur sudah full-stack, sebagian lain masih berupa UI atau model

7. RENCANA PENANDAAN NAMA DI DALAM KODE
==================================================

Format komentar Go:

// Author: [Nama]
// PBI: KF-xx
// Sprint: Sprint 1

Format komentar HTML:

<!-- Author: [Nama] -->
<!-- PBI: KF-xx -->
<!-- Sprint: Sprint 1 -->

Aturan penempatan:
- Diletakkan di atas func, type struct, route registration, atau blok script utama
- Tidak perlu di setiap baris
- Jika satu file berisi banyak fitur, gunakan beberapa blok komentar sesuai fungsi
- Jika satu fungsi dipakai lintas PBI, pilih PBI yang paling dominan

==================================================
8. CONTOH IMPLEMENTASI PENANDAAN
==================================================

Contoh pada Controller:

// Author: Aura
// PBI: KF-03
// Sprint: Sprint 1
func CreateJob(c *gin.Context) {
    // ...
}

Contoh pada Config:

// Author: Arga
// PBI: KF-17
// Sprint: Sprint 2
func ConnectDB() {
    // ...
}

Contoh pada Route:

// Author: Danu
// PBI: KF-06
// Sprint: Sprint 1
client.GET("/jobs/:id/applicants", controllers.GetJobApplicants)

Contoh pada Middleware:

// Author: Fadhil
// PBI: KF-02
// Sprint: Sprint 1
func AuthMiddleware() gin.HandlerFunc {
    // ...
}

Contoh pada Model:

// Author: Aura
// PBI: KF-03
// Sprint: Sprint 1
type Job struct {
    ID    uint
    Judul string
}

Contoh pada View:

<!-- Author: Rania -->
<!-- PBI: KF-09 -->
<!-- Sprint: Sprint 1 -->
<script>
async function loadApplications() {
  // ...
}
</script>

- Auth
- Profil client dan freelancer
- Dashboard
